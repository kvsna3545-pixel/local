GOD LUAU VAULT

ฝากสคริป Luau + ป้องกันโค้ด • ทำงานได้เลยบน GitHub Pages ไม่ต้องมีฐานข้อมูล

1. ใส่สคริป

เบา กลาง หนัก
ลบ Comment เปลี่ยนชื่อตัวแปร เข้ารหัส String ใส่ Watermark / ID ใส่โค้ดหลอก

2. โค้ดที่ป้องกันแล้ว

ก็อปไปใช้ได้เลย หรือกดดาวน์โหลดเป็น .luau

3. คลังสคริปของฉัน 0 สคริป

เก็บในเครื่องนี้ (localStorage) เปิดเว็บใหม่ก็ยังอยู่ ไม่ต้องรีเฟรช

4. ฝากขึ้น GitHub

สร้าง Token ที่ github.com/settings/tokens แบบ Classic เลือก scope repo + gist แล้ววางตรงนี้ Token จะไม่ถูกบันทึกถาวร

วิธีใช้ GitHub Pages

1. อัปไฟล์นี้เป็น index.html ใน repo
2. Settings > Pages > Branch main > Save
3. เปิด https://ชื่อผู้ใช้.github.io/ชื่อrepo/
